Neural Network Challenge

Step 1 — Inspect the model

This simulation uses a very simple neural network with 2 inputs and 2 neurons in one hidden layer (therefore 4 weights and 2 biases). Consequently, each data point is transformed into a 2-dimensional representation (an embedding with 2 values).

WeightsControl how the two input coordinates are combined through scale, shear, and rotation.
BiasesShift the values produced by the two hidden-layer neurons.
ActivationApplies a nonlinear function to each value.

Neural networks: Weights and biases transform the coordinate space

  • Weights can stretch, rotate, or shear the grid.
  • Biases shift the grid.
  • These transformations change the positions of data points relative to one another, potentially making classes easier to separate.

Activation functions introduce nonlinearity

  • They transform values nonlinearly, so proportional changes in input do not necessarily produce proportional changes in output.
  • This allows the coordinate grid to bend or distort, going beyond the stretching, rotation, shearing, and shifting produced by weights and biases.

Play the game and you'll see all these changes happen right in front of you!
