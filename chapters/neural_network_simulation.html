Neural Network Grid Lab

Experiment with weights and biases to transform a coordinate grid, then see how an activation function changes the representation.

Step 1 — Inspect the model

This simulation uses a very simple neural network with 2 inputs and 2 neurons in one hidden layer (therefore 4 weights and 2 biases). Consequently, each data point is transformed into a 2-dimensional representation (an embedding with 2 values).

WeightsControl how the two input coordinates are combined through scale, shear, and rotation.
BiasesShift the values produced by the two hidden-layer neurons.
ActivationApplies a nonlinear function to each value; it can be switched off for comparison.

In this lab, scale, shear, and rotation are convenient controls for the weight matrix; students do not adjust the four weights independently or train them with backpropagation.

The decision boundary is included to give you a concrete objective for the exercise. It is a teaching aid, not a realistic boundary intended to represent a real-world classification problem.

Weights and biases transform the coordinate space:

  • Weights can stretch, rotate, or shear the grid.
  • Biases shift the grid.
  • These transformations change the relative positions of data points, potentially making classes easier to separate.

Activation function introduces nonlinearity by breaking proportionality:

  • It transforms values nonlinearly, so changes in input no longer produce proportional changes in output.
  • This allows the coordinate grid to bend or distort, going beyond stretching, rotating, shearing, and shifting.

Play the game and you'll see all these changes happen right in front of you!

Keep in mind

Weights and biases shape the grid; activation functions make the overall mapping nonlinear.

  • Weights change the grid’s scale, orientation and shape through linear transformations.
  • Biases shift the grid.
  • Activation functions introduce nonlinearity: equal changes in the input do not necessarily produce equal changes in the output.

The key idea is the interaction: weights and biases determine the signal entering the activation function; the activation function transforms that signal nonlinearly.
