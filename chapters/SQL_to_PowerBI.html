2

Run this SQL query

The query joins each booking to its room-type description. The result stays at booking level, so Power BI can count bookings and summarize nights, occupants, room types, and dates.

SQL · Guesthouse booking data
SELECT
    b.booking_id,
    b.booking_date,
    b.guest_id,
    b.occupants,
    b.room_type_requested AS room_type_id,
    rt.description AS room_type,
    b.nights
FROM booking AS b
INNER JOIN room_type AS rt
    ON b.room_type_requested = rt.rt_id;

The resultset for the query will be displayed.

3

Build the report

Provide a semantic model name: guesthouse_business_analytics and click Create. Creating this workspace may take several minutes as Microsoft provisions your semantic model in the cloud. If it takes more than two minutes, click "My Workspace" in the left-side menu, and see if the new semantic model is listed. If it is listed, then it has been created.

  • Create a Total Bookings card.
    1. Select a blank area of the report canvas.
    2. In the Visualizations or Build a visual pane, choose the Card visual.
    3. Add booking_id to the card’s data field. Open the field’s menu and set its summarization to Count.
    4. With the card selected, open its formatting options and set the title to Total Bookings.
  • Create a Total Nights Booked card.
    1. Select a blank area of the report canvas.
    2. In the Visualizations or Build a visual pane, choose the Card visual.
    3. Add nights to the card’s data field. Open the field’s menu and set its summarization to Sum.
    4. With the card selected, open its formatting options and set the title to Total Nights Booked.
  • Create a card for the average of nights. Label it Average Stay (Nights).
  • Create a bar or column chart with room_type as the category and count of booking_id as the value.
  • Create a second chart using room_type and average nights, or use booking_date to show booking volume over time.
  • Add a slicer for room_type or booking_date. Select one or more values and observe which visuals change.

What this demonstrates

SQL does more than answer questions in a query window. It can select, combine, and shape the data that feeds a reporting application. Power BI then turns that query result into visual summaries and interactive ways to explore the business. The SQL query is part of the reporting pipeline.
