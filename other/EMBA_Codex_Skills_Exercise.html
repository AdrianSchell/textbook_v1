The executive challenge

You lead a fictional multi-region business. Revenue is growing, and leadership is considering expansion. But is the underlying business getting healthier?

In this lab you will create an Executive Performance Review skill in Codex: a repeatable method for examining financial, operational, and customer evidence, challenging management assumptions, and producing a concise briefing.

What makes this a Codex exercise? Codex will inspect real project files, calculate metrics, compare periods, create a briefing file, and repeat the process using your saved instructions. You are building a reusable capability—not merely writing a better one-off prompt.

What is a Codex skill?

A skill is a reusable set of instructions that tells Codex how to carry out a particular kind of work. Rather than explaining your preferred method every time, you save that method in a skill and ask Codex to apply it whenever the task arises.

In Codex, a skill is stored in a folder containing a file named SKILL.md. That file describes the skill's purpose, when to use it, and the steps or standards to follow. A skill can also include supporting scripts, templates, and reference files. Codex can use its tools to read business data, run calculations, and create output files while following those instructions.

Executive example: You repeatedly review quarterly business performance. Instead of retyping your criteria for evaluating margins, customer experience, operational risks, and management assumptions, you create an Executive Performance Review skill once. Next quarter, you invoke the same skill on new data.

Skills Codex already provides

Codex also supports built-in or bundled skills that help you work with skills themselves. Two useful examples are:

  • $skill-creator — Create or update a skill. Guides you through describing a repeatable task and generating its SKILL.md and supporting files. You will use this in Step 2.
  • $skill-installer — Add an existing skill. Helps install skills from supported collections or repositories, rather than building everything from scratch.

Browse available skills: In the Codex prompt box, type / to open the command and skills menu. Browse the available entries to discover skills you can use, such as Financial Budget if it is installed. Select a skill to see or invoke it. The list may vary by installation; you do not need to use Financial Budget for this exercise.

Skill availability depends on your Codex installation and configuration. If a named skill is not available, ask Codex what skills are installed; you can still create the project skill directly. In contrast to these general-purpose helpers, the Executive Performance Review skill you create will capture your own management approach.

Three ways to work with AI

As you complete the exercise, notice the progression from a one-time question to a reusable process that acts on files.

Important nuance: ChatGPT can also analyze files, produce deliverables, and reuse instructions. Codex's advantage in this exercise is its integrated, project-based way of working with files, tools, and reusable workflows—not an exclusive ability to analyze data.

Remember this progression: Prompt = what to do now. Skill = how to perform a recurring task. Agentic workflow = using skills, tools, data, and actions to complete the work.

Important distinction: A skill is not a new AI model and does not guarantee correct analysis. It packages a method that you can inspect, test, refine, and reuse. In this exercise, you will first work without a skill, then create one, apply it to a new quarter, and improve it.

Before you start

The Codex desktop app should already be installed on your laptop. If it is not installed, download the desktop application for Windows or macOS from the official OpenAI download page. Open the app, sign in with your ChatGPT account, and select Codex.

If you are using a work laptop, check with your organization that you are permitted to install and use Codex.

1. Establish a baseline

Run a straightforward request using Q1 only. Codex should read the files and create a first briefing. Notice what it includes and what it overlooks.

Read the files in the Q1 folder. Analyze business performance and write a concise executive briefing to baseline_review.md in the project root. Calculate relevant financial metrics and highlight important business issues. Do not read Q2 yet.

Reflect: What would you add to make this useful for an actual executive decision? Consider margin trends, data limitations, customer experience, and whether management claims are supported.

2. Build your executive skill

In Codex, invoke $skill-creator. It may respond with: “What skill should I create or update, and where should it live? Include its purpose and preferred folder path.” This is expected. Paste the response below into that same conversation. The folder path is relative to the project root you opened in Codex.

Create a new skill called executive-performance-review. Purpose: Act as my executive business analyst. Review quarterly financial, operational, customer-feedback, and management-notes files to identify performance changes, challenge assumptions, and produce a decision-ready executive briefing. My management approach: 1. Read the relevant files from the quarter folders in this project. 2. Calculate revenue, gross profit, gross margin, and operating profit (revenue minus COGS minus operating expenses); verify the arithmetic. 3. When two quarters are available, compare dollar and percentage changes, and show margin changes in percentage points. 4. Connect financial, operational, and customer signals without presenting correlation as proven causation. 5. Separate verified findings, hypotheses, and missing evidence. Never invent data. 6. Prioritize the three most consequential issues, with proposed actions, owners by role, and indicators to monitor. 7. Produce an approximately one-page Markdown briefing with an executive summary, key metrics, red flags, decisions, and open questions. 8. Save the briefing to the filename I specify. Do not overwrite an existing briefing without asking. Location: Create a project-specific skill at: .agents/skills/executive-performance-review/ Use SKILL.md as the main skill file. Before finalizing, ask me TWO short questions about how I personally evaluate management decisions. Incorporate my answers, create the skill on disk, show me its SKILL.md, and explain exactly how to invoke it.
Personalize it. Answer Codex's two questions using your own management priorities. For example: Which risks would cause you to delay expansion? Which early-warning metrics matter most to you?

Check the result: verify your skill was saved

Codex should have created a reusable skill file in your project:

  1. Open the emba_codex_exercise folder on your laptop.
  2. Navigate to .agents → skills → executive-performance-review. Note: folders beginning with a dot may be hidden in your file manager.
  3. Open SKILL.md in a text editor, or use Markdown Live Preview to view it in a formatted, easy-to-read layout.
  4. Confirm that it includes the management criteria you selected when creating the skill.

Easier alternative: Ask Codex to locate and explain the file using the prompt below.

Open the SKILL.md file for my executive-performance-review skill. Show me the management criteria it contains and confirm its exact location in this project. If the file does not exist, tell me clearly.
Key takeaway: You have created a reusable skill stored as a file—not simply a prompt in a chat conversation. Codex can apply it to future tasks without requiring you to repeat the full instructions.

If $skill-creator is unavailable, ask Codex directly to create the same folder and valid SKILL.md, using the prompt above. If Codex does not recognize the new skill immediately, start a new Codex conversation with the same project open.

3. Apply it to a new quarter

Now give Codex a new dataset and a much shorter instruction. Explicitly invoke the skill by name. Ask it to compare Q2 against Q1.

Use the executive-performance-review skill to analyze Q2 against Q1. Read the files in both folders, verify the calculations, and create q2_executive_briefing.md in the project root. What changed, what matters most, and should management accelerate expansion?

Look for the surprise: Is revenue growth accompanied by stronger profitability? Do delivery, returns, customer satisfaction, and overtime tell a consistent story? Is there enough evidence to establish why performance changed?

Expected deliverable: q2_executive_briefing.md, including verified financial comparisons and an evidence-based recommendation. A good answer may identify a deteriorating operating picture even while revenue rises.

4. Improve the skill—not just the answer

Review the briefing. Find one weakness in the analysis or its presentation. Change the underlying skill so the improvement applies next time, then rerun it.

Improve my executive-performance-review skill: prioritize margin deterioration and leading operational indicators before celebrating revenue growth. For every proposed action, specify the evidence supporting it and the additional evidence needed. Update SKILL.md, explain what changed, then rerun the Q2 review and save q2_executive_briefing_v2.md. Do not overwrite the earlier version.

Compare q2_executive_briefing.md and q2_executive_briefing_v2.md. The important change is not only a better report: you have improved the reusable management process.

5. Executive discussion

  1. From prompting to delegation: What did Codex actually do with the project files beyond generating text? Which steps required your managerial judgment?
  2. Encoding expertise: What did your SKILL.md capture about your management approach? How did updating the skill differ from revising a single answer?
  3. Organizational scale: If 50 managers used this skill, who should approve its methodology, maintain it, verify its calculations, and audit its outputs?

The Q3 challenge

Imagine the next quarter has arrived. Your team adds a Q3 folder with the same four types of business files. How much instruction would you need to give Codex to produce the next executive briefing?

Use my executive-performance-review skill to review Q3 against Q2, check the calculations, and save the next executive briefing in the project folder.

This is a thought experiment; no Q3 files are supplied. Do not run the prompt unless Q3 data have been added.

Discussion: You are no longer reconstructing the analytical method each quarter. You are delegating a recurring process using a method you can inspect and improve.

ChatGPT can also analyze files, create deliverables, and reuse instructions. This comparison emphasizes Codex's project-based workflow and the value of a saved, repeatable skill.

Prompt: specify the task you want AI to perform now. Skill: package the method for recurring work in an inspectable, reusable file. Agentic workflow: combine that method with project data, tools, calculations, and saved deliverables.

The executive insight: Instead of repeatedly instructing AI to do work, you can develop reusable management methods that AI applies to new situations. Organizational expertise can become easier to share, improve, and scale—but still needs human judgment, validation, and governance.
